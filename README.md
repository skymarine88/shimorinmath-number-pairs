# SHIMORINMATH — математические тренажёры

Общий каталог: https://skymarine88.github.io/shimorinmath-number-pairs/

- `linear-function/` — линейная функция.
- `quadratic-function/` — квадратичная функция.
- `quadratic-equations/` — «Спасибо, месье Виет!».
- `trigonometry/` — единичная окружность, градусы и радианы, табличные значения и приведение.
- `arithmetic/` — начальная школа, серии вычислительных карточек.
- `vectors/` — векторы: подготовительные задания и прототипы ЕГЭ.

Из каждого тренажёра ссылка «Все тренажёры» ведёт в общий каталог.

Публикация: GitHub Pages, ветка main, корень репозитория. Общая навигация — `catalog-nav.css`. Старая главная «Подбери пару» сохранена по адресу `number-pairs.html`; она не включена в каталог.

Шиморин Б.В. · SHIMORINMATH

Следующий этап: полноценный прогрессбар освоения навыков. Сброс видимых счётчиков хранит отдельную точку отсчёта для подготовки и ЕГЭ; история решений сохраняется для расчёта прогресса.

Рабочая сводка для «Главного штаба SHIMORINMATH»: [docs/SHIMORINMATH_HQ.md](docs/SHIMORINMATH_HQ.md).

Косинус угла: в любой последовательности из десяти новых заданий не более одной коллинеарной пары. Общая последовательность подготовки и обоих прототипов ЕГЭ сохраняется между сеансами; пропуски также учитываются.
