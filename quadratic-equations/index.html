Два способа

1. Теорема Виета

Для x² + px + q = 0 ищем два числа, сумма которых −p, а произведение q.

Например, x² − 5x + 6 = 0: сумма 5, произведение 6. Корни: 2 и 3.

2. Метод переброски

Для ax² + bx + c = 0 сначала ищем корни вспомогательного уравнения t² + bt + ac = 0.

Например, 2x² + 7x + 3 = 0. Получаем t² + 7t + 6 = 0. По Виету t₁ = −1, t₂ = −6. Затем x₁ = −1/2, x₂ = −3.

Важно: коэффициент a «перебрасывается» к c, а найденные вспомогательные корни обязательно делятся на a.
