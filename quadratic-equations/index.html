Теория

ax² + bx = 0

Вынести x: x(ax+b)=0. Тогда x=0 либо ax+b=0. На x делить нельзя: потеряешь нулевой корень.

ax² + c = 0

x²=−c/a. Если правая часть положительна, два противоположных корня. Если отрицательна, действительных корней нет.

ax² + bx + c = 0

D=b²−4ac. Если D<0 корней нет, D=0 один, D>0 два. Корни x₁,₂=(−b±√D)/(2a).

Дискриминант можно использовать и для неполных квадратных уравнений.
