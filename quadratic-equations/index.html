🧠 Теория подбора корней (обратная теорема Виета)
Рассматриваем приведённое уравнение x² + b x + c = 0. Если его корни целые, то:
x₁ + x₂ = −b и x₁·x₂ = c
1) Где искать корни
  • Если корни целые, то они обязательно являются делителями числа c, потому что x₁·x₂ = c.
  • Значит, кандидаты — это числа ±d, где d делит |c|.
2) Сразу определить знаки корней по c
  • c > 0 ⇒ корни одного знака (оба + или оба −).
  • c < 0 ⇒ корни разных знаков (один +, другой −).
  • c = 0 ⇒ один корень 0, второй равен −b.
3) Если корни одного знака — какой именно
Здесь c > 0.
  • −b > 0 ⇒ сумма положительная ⇒ оба корня положительные.
  • −b < 0 ⇒ сумма отрицательная ⇒ оба корня отрицательные.
4) Если корни разных знаков — кто больше по модулю
Здесь c < 0.
  • −b > 0 ⇒ “перевешивает” положительный ⇒ |положительный| > |отрицательный|.
  • −b < 0 ⇒ “перевешивает” отрицательный ⇒ |отрицательный| > |положительный|.
5) «Конструктор» делителей из простых множителей
Разложи |c| на простые множители, например: |c| = 72 = 2³·3².
Любой делитель собирается как конструктор: 2^α·3^β, где α = 0…3, β = 0…2. Дальше добавляешь знак (±) и проверяешь условия суммы и произведения.
⚡ Быстрые фильтры по делимости (ускоряют подбор)
Чётность (делимость на 2)
  • Так как x₁ + x₂ = −b, то чётность суммы задаётся чётностью b.
  • b нечётный ⇒ −b нечётный ⇒ корни разной чётности (один чётный, другой нечётный).
  • Тогда, если c чётное, весь множитель 2^k из разложения |c| обязательно находится в чётном корне, а второй корень — нечётный (в нём нет двойки).
Обобщение: работа по остаткам (mod p)
Можно использовать любой простой делитель p:
x₁ + x₂ ≡ −b (mod p) и x₁·x₂ ≡ c (mod p).
Например, если c кратно 3, то хотя бы один корень кратен 3. Тогда второй корень должен давать нужный остаток по модулю 3, чтобы сумма стала равной −b.
Как понять, что весь множитель pᵏ «сидит» в одном корне
Если из условия по сумме видно, что один корень не делится на p, а c делится на p, то вся степень pᵏ из разложения |c| обязательно находится в другом корне. (Для p = 2 это как раз типичная ситуация при нечётном b.)
6) Финальная проверка пары
  • Выбрал делители p и q.
  • Проверил: p·q = c и p + q = −b.
  • Если оба условия выполнены — это и есть корни.
На уровне 2 сначала решаем вспомогательное y² + b y + C = 0 (где C = a·c), а потом делим корни на a: x = y/a.
