Сложность:
Как найти уравнение по двум точкам?

1. Найди угловой коэффициент: k = (y₂ − y₁) / (x₂ − x₁).

2. Подставь любую заданную точку в y = kx + b и вычисли b.

3. Проверь полученное уравнение на второй точке. Две точки с разными абсциссами задают единственную прямую вида y = kx + b.

Теория (коротко и по делу)
Линейная функция: y = kx + b.

k

  • k > 0 — вверх вправо, k < 0 — вниз вправо.
  • Чем больше |k|, тем прямая круче.

b

  • b — пересечение с осью Oy: точка (0; b).

Пересечения

  • С Oy: (0; b).
  • С Ox: y=0 ⇒ 0=kx+b ⇒ x=−b/k (если k≠0).

∥ и ⟂

  • Параллельные: одинаковый k.
  • Перпендикулярные: k₂=−1/k₁ (если k₁≠0).
Ввод: десятичные (точка/запятая) и дроби 3/2.
