Теория

Вершина и точка

Для вершины V(m; n) функция имеет вид f(x) = a(x − m)² + n. Пусть P(u; v) — другая точка параболы. Подставьте её координаты, чтобы найти a = v − n(u − m)². При a > 0 ветви направлены вверх, при a < 0 — вниз.

Например, для V(2; 3) и P(4; 1) получаем 1 = 4a + 3, поэтому a = −½.

Три точки

Подставьте координаты каждой точки в y = ax² + bx + c и решите систему. Три точки с разными абсциссами задают параболу, если они не лежат на одной прямой.

Например, точки (0; 1), (1; 2) и (−1; 4) дают c = 1, a + b = 1 и a − b = 3. Сложение последних двух уравнений даёт a = 2, откуда b = −1. Получаем f(x) = 2x² − x + 1.

Значение функции и аргументы

Чтобы найти f(t), подставьте t вместо x. В примере выше f(−1) = 4. Чтобы найти все аргументы, при которых f(x) = 4, решите 2x² − x − 3 = 0. Корни равны −1 и 1,5.

Дискриминант и вершина

Запишите функцию в виде f(x) = ax² + bx + c. Дискриминант равен D = b² − 4ac. Абсцисса вершины m = −b2a, ордината n = f(m).
