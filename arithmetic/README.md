# SHIMORINMATH — Вычисления

Карточная практика для 2–5 классов. Цель — точное самостоятельное выполнение арифметических действий и последовательное исправление ошибок.

10 навыков; серии из 10/20/30/50 уникальных заданий. Табличные множители 1–10. Умножение содержит все упорядоченные пары натуральных множителей с произведением до 100/200; внетабличный банк исключает пары, где оба множителя не больше 10. Минимумы каждого множителя задаются независимо, по умолчанию 2. Деление без остатка. Уровень до 200 включает весь диапазон до 200. Серия сокращается до размера базы, если в ней мало пар; пустой банк блокирует старт с пояснением. В каждом задании сложения/вычитания есть перенос/заимствование из десятков в единицы.

Неверные задания уходят в конец очереди повторения. «Править ошибки» прекращает новые задания, включая текущую ещё не решённую карточку; отложенные задания не включаются в итог решённой части. Исправления считаются отдельно от первых попыток. Правильный ответ раскрывается только при включённой настройке. Повторное решение после раскрытия ответа не считается самостоятельной первой попыткой.

Прогресс локальный, без персональных данных и сетевой передачи; восстановление после перезагрузки. Фирменный знак целиком поворачивается на −90° за 600 ms, удерживается 900 ms и возвращается за 600 ms; один раз при старте без активной серии и по нажатию. При reduced motion неподвижен.

Никакой пятибалльной оценки или недоказанных нормативов скорости. Для освоения рекомендуется новая серия без раскрытия ответов.

Статический сайт без сборки и сторонних зависимостей. `node arithmetic/test.cjs` проверяет все банки и цикл очереди. Для локального просмотра: `python3 -m http.server 8765`, затем `/arithmetic/`.

Фирменный готовый Logo White взят без изменений из официального ресурса репозитория. Применены Brandbook v1.1 и DesignTokens: тёмная тема, фирменные состояния, системные резервные шрифты Arial и математический serif при отсутствии Manrope/STIX, клавиатура, мобильный ввод, reduced motion.
